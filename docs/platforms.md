# 平台能力与真机验收

## 已实现的共享能力

Flutter 控制台、自适应导航、单选 / 多选 / 填空 / 听力练习、错题本、题库导入、应用密码和本地数据库使用同一份代码。桌面 / 平板 / 手机断点分别为 ≥900、600–899、<600 逻辑像素。

已设置应用密码时，打开管理应用和从后台返回需验证；会话内修改设置、管理应用或题库无需重复验证。短暂失去焦点不会结束会话。验证界面覆盖打开的页面和弹窗，验证后回到原页面。自动触发的答题拦截沿用答题解锁流程；缺少题目时可打开管理入口，经过应用密码验证后调整题库。

数据库使用 Drift + SQLite；网页通过本地 sqlite3.wasm 和 Drift worker 自动选择可用的浏览器持久化方式。代码没有把浏览器显示为已经具有系统级管控能力。浏览器存储仍受清除网站数据、隐私模式和存储额度影响。

## Android 原生实现

`pigeons/native_monitor_api.dart` 定义通信协议，生成的 Dart / Kotlin 文件已提交工程。

- `MonitorHost`：读取可启动的非系统应用和系统应用分类、检查真实权限状态、打开系统授权页、同步策略。
- `StudyAccessibilityService`：仅订阅窗口切换，不读取窗口文字；每秒更新计时和提醒。计时使用 `SystemClock.elapsedRealtime()`，锁屏或屏幕熄灭时停止累计。
- `GuardEngine`：累计 / 独立计时、每日使用量、持久化周期、提前 60 秒提醒、设置保护及电话应用豁免。日期变更不会清空当前娱乐周期。
- `LockActivity`：打开 `/intercept` Flutter 入口；在完成题目或确认紧急跳过后关闭。Flutter `PopScope` 阻止返回手势，键盘 Esc 在强制模式中被消费。
- `StudyAdminReceiver`：设备管理器由设备所有者主动激活，应用内解除入口由管理应用的入口密码保护。

必须在设备上由用户明确开启所需权限。普通应用无法保证阻止系统 Home、强制停止、安全模式、权限撤销或所有厂商的后台清理；本工程不会宣称设备管理器等于设备所有者（Device Owner），也不把设备管理器授权显示为绝对禁止卸载。

验收步骤：

1. 安装调试 APK，设置应用密码；重新启动应用、从后台切回，确认需要验证；验证后修改设置不再要求重复输入。
2. 在安全中心逐项开启应用使用情况、无障碍和悬浮窗权限；设备管理保护为可选项。
3. 选择两个实际安装的应用，配置累计模式，确认切换应用后计时连续。
4. 达到阈值前 60 秒检查提醒自动递减、宽度约为屏幕的 95% 且水平居中；阈值到达检查拦截、返回键、手势、旋转和软键盘。
5. 答错一次，确认 5 秒内不能下一题；完成题数后确认解锁和周期归零。
6. 测试独立时长、熄屏、来电、拨号、后台重启、设备重启和修改系统时间。
7. 进入已验证的管理应用后暂停守护或解除设备管理；确认仍可从系统撤销授权。

## iOS / macOS / Windows

这些平台提供共享学习界面和本地数据能力。**系统前台应用监控、系统级拦截与防卸载尚未接入，UI 会明确显示“当前平台未接入”。**

iOS 的 Screen Time 方案需要 Apple Family Controls entitlement、DeviceActivityMonitor / Shield 扩展、App Groups、设备授权、签名和真机测试。ManagedSettings 的 Shield 不支持直接嵌入任意 Flutter 全屏答题页，需在实际产品流程中设计符合系统约束的学习解锁路线。

桌面端若要达到需求中的系统守护强度，需要继续实现 Windows 前台窗口监控和后台服务，或 macOS NSWorkspace / LaunchAgent，以及权限撤销与服务停止流程。普通 Flutter 置顶窗口本身不等于防卸载服务。

## 已知边界

- 每日统计和跳过额度按设备本地日期存储；原生周期采用单调时钟。跨设备同步、可信时间与防篡改存储不在当前实现中。
- 原生今日使用时间在控制台打开或恢复时同步；跨日历史后台归档仍需补齐。
- 内置 28 题是可运行样例题库。新题库导入后应由维护者检查内容准确性和版权。
- 支持 JSON、CSV、含音频的 ZIP，不支持 Anki `.apkg` 或 Excel `.xlsx`。
- 当前数据库以事务保存完整状态，适合本地小题库；大规模题库需要进一步细化增量写入。
- Android 调试包使用调试签名。商店发布前需配置正式签名与应用商店权限说明。
