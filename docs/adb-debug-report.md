# Android ADB 实机调试记录

2026-11-10，三星 SM-S9280，Android 15 / API 35，学霸锁 1.0.1（versionCode 2）。

## 结果与原因

拦截前的提醒无需触屏即可持续递减，到期自动打开答题页。

原问题来自悬浮提醒产生的本应用窗口事件：无障碍服务将其误判为用户返回学霸锁，使受控应用计时暂停；再次操作受控应用才重新开始计时。修复后忽略悬浮窗的本应用事件，并通过真实页面的生命周期与焦点报告返回学霸锁的行为。

## 测试过程

用户已在手机配置监督 PIN 并授权应用使用情况、无障碍与悬浮提醒，也已同意临时 1 分钟测试。调试未读取 PIN 内容。

临时安装独立的静态测试页面，仅将该页面设为受控应用，使用 1 分钟累计策略。页面自行保持亮屏；倒计时观察期间只读取计时状态和截图，没有发送触屏、按键或滑动事件。
